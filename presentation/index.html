CSS Grid Layout

Modern Layouts Made Easy

By Alina

Key Terminology

  • Grid Container: Defines the grid layout.
  • Grid Items: Direct children of the grid container.
  • Grid Lines: Dividing lines for rows and columns.
  • Grid Tracks: Space between grid lines.
  • Grid Cell: Smallest unit in the grid.
  • Grid Area: Rectangular space in the grid.

Supported Units

  • Absolute Units: px, cm, mm, in
  • Relative Units: %, em, rem
  • Grid-Specific Units: fr, auto

Grid with Media Queries

Change the grid layout based on screen size.


        .grid-container {
          display: grid;
          grid-template-columns: repeat(3, 1fr);
          gap: 10px;
        }
        @media (max-width: 600px) {
          .grid-container {
            grid-template-columns: 1fr; /* Single column on small screens */
          }
        }
